# CAR

A SIMPLE CARDBOARD CAR

## Description

I MADE THIS USING SCRAPS FROM THE TOYS I FOUND. IT IS JUST A SIMPLE WORKING CAR MODEL WITH FORWARD AND BACKWARD MOVEMENT USING A WIRED REMOTE.

## Getting Started

### Dependencies

* A MOTOR
* SOME GEARS
* TYRES
* CARDBOARD
* BATTERY
* BUTTON
* WIRES
* CHARGING MODULE

### Installing

* CHECK THE IMAGES FOLDER
* THERE WILL BE EVERY PHOTO AND VIDEO YOU NEED TO MAKE THIS

### Executing program

* CHARGE THE BATTERY
* USE THE WIRED REMOTE TO MOVE THE CAR FORWARD AND BACKWARD
